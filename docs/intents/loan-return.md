# intent: 備品の返却（記入例）

- 起票 Issue: #（要望 Issue の番号）
- 起案者: 総務部
- 状態: マージ済み（PO 承認）

## 問題

備品を返したかどうかを、総務部が貸出台帳の Excel に手で記入している。記入漏れが月に数件あり、返したはずの備品が「貸出中」のまま残る。次に借りたい人が借りられず、総務部に問い合わせが来る。

## 期待する結果

- 借り手が自分で返却を記録できる。記録した時点で、その備品はすぐに借りられる状態になる
- 窓口で受け取った場合は、総務部（管理者）が代理で返却を記録できる
- 誰がいつ返却を記録したかを後から確かめられる

## 影響を受ける利用者とシステム

| 対象 | 影響 |
|---|---|
| 借り手（社員） | 返却を自分で記録する |
| 総務部（管理者） | 代理で返却を記録する。台帳への手入力がなくなる |
| 備品一覧 API（GET /items） | 返却後に `available: true` になる |

## 制約

- 他人の貸出を返却できてはいけない（いたずらや誤操作で台帳がずれる）
- 期限を過ぎていても返却は受け付ける（返してもらうことが最優先）

## 未解決の問い

- 返却時に備品の状態（破損など）を記録するか → 今回は扱わない。必要になったら別の intent にする
