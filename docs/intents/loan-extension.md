# intent: 貸出の延長

- 起票 Issue: #（講師が用意した要望 Issue の番号）
- 起案者: 開発部
- 状態: マージ済み（PO 承認）。2周目（Day2）は講師が用意したこの intent から始める

## 問題

検証用の PC やモニターを2週間借りても、検証が終わらないことがある。いまは一度返却して借り直しているが、返却した瞬間に別の人に借りられてしまい、作業が止まる。総務部にも「延長できないか」という問い合わせが週に数件来ている。

## 期待する結果

- 借り手本人が、返却期限の前に自分で貸出を延長できる
- 延長に上限があり、同じ人が備品を抱え続けることはない
- 期限を過ぎた貸出は延長できず、まず返却してもらう

## 影響を受ける利用者とシステム

| 対象 | 影響 |
|---|---|
| 借り手（社員） | 期限前に自分で延長する |
| 総務部（管理者） | 延長の問い合わせ対応がなくなる。延長の記録を監査ログで確かめる |
| 期限超過一覧 API（GET /loans/overdue） | 延長後の返却期限で判定される |

## 制約

- 延長は1回まで。延長期間は7日
- 期限超過中は延長できない
- 延長できるのは借り手本人だけ。管理者も代理で延長しない（延長は借り手の意思で行う）

## 未解決の問い

- 次に借りたい人の予約がある場合に延長を断るか → 予約機能がないので今回は扱わない
