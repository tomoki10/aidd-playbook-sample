# intent: 備品の空き状況と自分の貸出の確認

- 起票 Issue: #1（[要望] 空いている備品と自分の貸出を確かめたい）
- 起案者: 総務部
- 状態: マージ済み（PO 承認）

## 問題

「いま空いているノート PC はあるか」「自分が借りている備品の返却期限はいつか」という問い合わせが、毎日10件ほど総務部に来る。総務部はそのたびに貸出台帳を開いて答えていて、1日30分ほどかかっている。社員の側も、総務部の返事を待たないと借りに行けない。

## 期待する結果

- 社員が自分で、いま借りられる備品を種類ごとに確かめられる
- 社員が自分で、自分が借りている備品とその返却期限を確かめられる
- 総務部への空き状況と返却期限の問い合わせがなくなる

## 影響を受ける利用者とシステム

| 対象 | 影響 |
|---|---|
| 社員（借り手） | 空いている備品と、自分の貸出と返却期限を自分で確かめる |
| 総務部（管理者） | 空き状況と返却期限の問い合わせ対応がなくなる |
| 備品一覧 API（GET /items） | 種類と空き状況で探せるようになる。既存の呼び出し方はそのまま使える |
| 貸出 API | 自分の貸出を確かめる参照が増える。既存の貸出・返却には影響しない |

## 制約

- ほかの社員が何を借りているかは見せない。自分の貸出だけが見られる
- 備品の空き状況を見せるときに、誰が借りているか（借り手の氏名や連絡先）は見せない
- 来月の棚卸しまでに使えるようにする

## 未解決の問い

- 「空いている」をどう判定するか。返却期限を過ぎてまだ返っていない備品は空いているとみなすか → spec で決める
- 「自分が借りているもの」に返却済みの貸出を含めるか → spec で決める
- 返却期限が近づいたら知らせるか → 今回は範囲外とし、要望があれば別の intent にする
