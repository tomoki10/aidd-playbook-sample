# Plan B1: 貸出延長のドメイン関数の実装

## Approach

1. 借り手本人の、返却前で返却期限の当日までの貸出だけを延長できるようにする
2. 延長すると返却期限が現在の返却期限から7日延び、延長は1回までにする
3. 延長できない理由は、Issue の判定順で先のものを1つだけ返す

## Risks

- 期限当日を期限超過として扱うと、当日の延長（R3）ができなくなる
- 境目の関数の形を変えると、並行している B2 の呼び出しが壊れる

## Verification

- Issue の受入テストの観点と期待値を、実装と同じ PR でテストにし、テスト名に R 番号を付ける
- 期限の当日と翌日、延長回数の上限、本人以外の境目をテストで確かめる
- lint、typecheck、test がすべて通ることを確認する
