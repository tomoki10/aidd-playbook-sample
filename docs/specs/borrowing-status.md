# spec: 備品の空き状況と自分の貸出の確認

- 元の intent: [docs/intents/borrowing-status.md](../intents/borrowing-status.md)（総務部）
- 状態: 受け入れ済み（PO 承認）
- 適用した Skill: secure-api

## 要件

- R1. 社員は、備品を種類で絞り込んで一覧できる
- R2. 社員は、いま借りられる備品だけに絞り込める。「いま借りられる」は、返却されていない貸出がないこと（返却期限を過ぎても、返却されるまでは貸出中）
- R3. 備品の一覧には、借り手の情報を含めない
- R4. 社員は、自分が借りている貸出中の備品と返却期限を一覧で見られる。返却済みの貸出は含めない
- R5. ほかの社員の貸出は見られない

## 設計

- 既存の備品一覧に絞り込みを足す
- 自分の貸出の一覧を、既存の認証の後ろに足す。本人は認証から特定し、利用者 ID をクライアントから受け取らない
- どちらも既存のデータを読むだけで、新しいデータは持たない

## intent の制約をどう満たすか

| 制約 | 満たし方 |
|---|---|
| ほかの社員の貸出は見せない | R5。認証した本人の分だけ |
| 個人情報を広げない | R3。備品の一覧に借り手を含めない |
| 来月の棚卸しまでに使えるようにする | 設計。既存のデータの参照だけで作る |

## intent で解決しない問い

- 返却期限の前に知らせるか → 今回は扱わない（懸念1）

## 懸念点

1. 期限が近いことは、社員が自分で見に来ないと分からない。通知は別の要望で扱う。担当: 総務部
